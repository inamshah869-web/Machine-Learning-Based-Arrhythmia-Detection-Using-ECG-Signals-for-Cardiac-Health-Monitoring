# Machine-Learning-Based-Arrhythmia-Detection-Using-ECG-Signals-for-Cardiac-Health-Monitoring
This project classifies arrhythmia from ECG data. It involves data preprocessing (imputation, scaling, PCA, SMOTE), training various ML/DL models (SVM, RF, CNN, LSTM, Ensemble), and evaluating their performance using accuracy and F1-scores. An ensemble model showed top performance.
